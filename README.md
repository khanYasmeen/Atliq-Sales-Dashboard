# Atliq-Sales-Dashboard

### 1. Objective 
The objective of this project is to analyze and visualize the overall sales performance of AtliQ Company. The dashboard provides a single view of total revenue, top customers, best-performing products, and high-revenue markets, eliminating the need to explore multiple SQL tables manually


### 2. Purpose 
This project simplifies business decision-making by connecting SQL data directly with Excel. It enables AtliQ’s management to monitor revenue trends and customer performance efficiently through a dynamic and interactive dashboard.


### 3. 🗃️ Data Source

The data originates from a SQL database containing multiple tables such as:
sales
customers
products
transactions
markets

Data from these tables was extracted using SQL joins and transformations before being imported into Excel.

### 4. 🧠 Process & Workflow
#### 1. Data Extraction (SQL)
Connected to the SQL database and read all tables.
Performed JOIN operations to merge multiple datasets.
Applied filtering, ordering, and transformation to clean and structure the data.

#### 2. Data Modelling (Excel)
Connected Excel to SQL and imported all tables.
Built relationships between tables using Power Pivot.
Handled missing or null values in relevant rows and columns.

### 5. Goal
- To calculate total revenue generated across all regions.
- Identify top customers contributing to overall sales.
- Highlight top 5 cities generating the highest revenue.
- Display top-selling products.
- Analyze sales trends year-over-year for performance tracking.

### 6. 📈 Key Insights
* Total Revenue: 987M
* Total Quantity Sold: 2M
* Top City: Delhi NCR (520.7M revenue)
* Top Customer: Electricalsara Stores (413.9M revenue)
* Top Zone: North Zone (68% of total revenue)
* Top 5 Products contributed the majority of sales revenue
* Yearly sales trend shows steady growth until 2018, followed by a slight decline
